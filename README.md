# PokeOpenWorld

A private, non-commercial open-world reimagining of the mainline Pokémon games,
built in Godot 4.7.2 with an HD-2D look. The current goal is the Kanto vertical
slice: Pallet Town → Route 1 → Viridian City → Route 2 → Viridian Forest.

- Design: `docs/superpowers/specs/2026-10-28-kanto-vertical-slice-design.md`
- Plan: `docs/superpowers/plans/2026-10-28-kanto-vertical-slice.md`

## Playing a build on Windows

1. Open the repository on GitHub and go to the **Actions** tab.
2. Click the newest successful **build** run.
3. Under **Artifacts**, download **OpenWorldRemake-windows** and unzip it.
4. Run `OpenWorldRemake.exe`. Windows SmartScreen may warn because the build is
   unsigned: choose **More info → Run anyway**.

## Assets policy

This repository contains **no Nintendo, Game Freak or The Pokémon Company
assets**. It ships simple placeholder art generated by `tools/gen_placeholders.gd`.

To use your own art or audio locally, create a `user_assets/` folder next to
`OpenWorldRemake.exe` containing a `manifest.json` that maps keys to files:

```json
{
  "species/pidgey": "sprites/pidgey_sheet.png",
  "species/pidgey_shiny": "sprites/pidgey_shiny_sheet.png",
  "music/route_1": "music/route1.ogg"
}
```

Anything missing or unreadable falls back to the placeholder and is logged to
`%APPDATA%\Godot\app_userdata\Open World Remake\logs\assets.log`.
`user_assets/` is git-ignored; never commit its contents.
